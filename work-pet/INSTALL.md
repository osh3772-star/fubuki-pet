# ChatGPT Work에 후부키 추가하기

Work 웹 펫과 독립 Windows 프로그램은 설치 경로가 다릅니다.

가장 간단한 배포 방식은 소유자가 만든 공식 펫 공유 링크입니다. 링크를 받은 사람은 자신의 ChatGPT 계정으로 입양한 뒤 펫을 선택합니다.
현재 검토 패키지에는 공개 공유 링크가 없습니다. 링크를 생성하거나 공개한 상태로 안내하지 마세요.

공유 링크가 준비된 뒤 ChatGPT에서 아래처럼 요청할 수 있습니다.

> 이 후부키 공유 링크의 펫을 내 라이브러리에 입양하고 활성화해 줘: [공식 펫 공유 링크]

대안은 `spritesheet-v2.png`를 ChatGPT Work에 첨부하고 다음과 같이 요청하는 방법입니다.

> 첨부한 스프라이트 시트를 검증한 뒤 Fubuki라는 이름의 Work 펫으로 추가하고 활성화해 줘.

설치 작업은 Pets 기능·플러그인을 사용할 수 있는 계정에서 이루어집니다. 생성 시 검증·업로드·스캔을 거치므로 한 번의 클릭으로 무조건 완료되지는 않습니다.
공유 링크의 접근 범위는 개인 계정과 조직 워크스페이스 설정에 따라 달라질 수 있습니다.

검토된 파일은 투명 PNG 1536×2288, v2 11행, 73프레임입니다. 실제 Pets 검증 도구가 이 형식을 통과시켰습니다.
공식 공개 문서의 웹 업로드 설명은 아직 1536×1872 v1만 명시하므로, 해당 화면에서 v2가 거절되면 파일을 임의로 자르지 말고 Pets 플러그인 지원을 확인하세요.

웹에서는 Settings → Personalization → Pet에서 선택합니다. 데스크톱 앱의 로컬 펫과 자동 동기화된다고 안내하지 않습니다.
독립 Windows 버전은 `FubukiPet-Windows-x64-Setup` 설치 경로를 따릅니다.

공식 사용 안내: https://learn.chatgpt.com/docs/pets
