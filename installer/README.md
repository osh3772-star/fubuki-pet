# Windows 설치 프로그램 만들기

이 스크립트는 아직 공개되지 않은 검토용 설치 파일을 만듭니다.
배포 파일의 라이선스 검토를 끝내기 전에는 공개 릴리스에 올리지 마세요.

Inno Setup 7.1.1에서 다음 명령으로 컴파일합니다.

```powershell
& '<Inno Setup 폴더>\ISCC.exe' '/DBundleDir=<FubukiPet 폴더 절대 경로>' '/DOutputDir=<출력 폴더 절대 경로>' installer/FubukiPet.iss
```

관리자 권한 없이 현재 사용자 계정의 Programs 폴더에 설치하며, 시작 메뉴 항목과 제거 프로그램을 만듭니다.
Python·서버·ChatGPT 로그인은 필요하지 않습니다. 자동 시작, 이벤트 훅, 네트워크 다운로드는 설치 과정에 없습니다.
설치 후 시작 메뉴에서 실행합니다. Windows 설정의 설치된 앱에서 제거할 수 있고, 사용자의 펫 설정은 보존됩니다.

테스트 빌드는 `/DTestMode=1`을 추가합니다. 이 빌드는 시작 메뉴와 Windows 제거 목록을 변경하지 않습니다.
테스트 대상 폴더를 `/DIR="..."`로 지정해 파일 배치·실행·제거를 확인할 수 있습니다.
일반 빌드의 시작 메뉴·설치된 앱 등록은 별도 실제 사용자 환경 검증이 필요합니다.

설치 파일은 서명되지 않았습니다. 보안 프로그램이나 SmartScreen 우회를 설치 절차로 안내하지 않습니다.
