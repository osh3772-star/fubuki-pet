Fubuki Pet 1.0

후부키 독립형 데스크톱 펫입니다. ChatGPT 내부 펫 설치와는 별도 프로그램입니다.
기존 그림과 상호작용 코드를 통합했습니다. 화면에서의 사용감과 그림 검수는 사용자에게 맡깁니다.

1. Windows 실행 파일 묶음
   ZIP 전체를 원하는 폴더에 압축 해제하고 FubukiPet.exe를 더블클릭하세요.
   _internal 폴더를 함께 보관하세요. EXE만 옮기면 실행되지 않습니다.
   Python 설치, 서버 실행, 계정 로그인 없이 실행하는 휴대용 방식입니다.
   소스 ZIP에는 EXE가 없습니다. 소스 실행 방법은 아래 2번입니다.

2. Windows 소스 실행
   Python 3.11~3.13 64비트가 있다면 START_FUBUKI.cmd를 더블클릭하세요.
   처음 실행할 때 이 폴더 안의 .venv에 필요한 패키지를 설치합니다. 인터넷이 필요합니다.
   이후에는 같은 파일을 열면 됩니다. 동작 패널은 run_windows.cmd --debug로 열 수 있습니다.
   build_windows.cmd는 현재 Windows에서 EXE와 휴대용 ZIP을 만듭니다.
   빌드 결과는 dist 폴더에 저장됩니다. 사람의 검수 완료를 요구하지 않습니다.

3. 사용
   - 왼쪽 클릭: 클릭 반응. 더블클릭: 점프.
   - 캐릭터를 잡고 이동: 방향별 드래그. 놓으면 관성/중력에 따라 낙하 후 착지·회복.
   - 머리 위를 천천히 왕복 이동: 쓰다듬기 반응.
   - 오른쪽 클릭 또는 작업 표시줄의 숨겨진 후부키 아이콘: 메뉴.
   - 크기, 항상 위에 표시, 움직임 줄이기를 메뉴에서 변경할 수 있습니다.
   - 화면으로 다시 데려오기: 현재 화면의 바닥으로 이동합니다.
   - 동작 패널 / 상태 보기: 애니메이션과 작업 상태를 직접 고릅니다.
   - 종료: 메뉴의 종료. 로그인 자동 시작은 메뉴에서 직접 켤 때만 적용됩니다.
   - 이미 실행 중이면 두 번째 실행은 중복 펫을 만들지 않습니다.

4. 설정 및 로그
   Windows: %LOCALAPPDATA%\FubukiPet
   Linux: ${XDG_DATA_HOME:-~/.local/share}/FubukiPet
   설정은 자동 저장합니다. 이전 시험판 FubukiPetPrototype 설정은 덮어쓰지 않습니다.
   실행 문제가 있으면 logs/launch.log를 확인하세요.
   개발용 FUBUKI_DATA_DIR 환경변수로 별도 설정 폴더를 지정할 수 있습니다.

5. 작업 상태 연결
   기본값은 꺼짐입니다. 메뉴에서 로컬 이벤트 수신을 켜면 파일 기반 이벤트를 받습니다.
   tools/emit_event.py로 working, thinking, waiting, success, failed, review, idle을 보낼 수 있습니다.
   tools/codex_hook_bridge.py는 기존 공개 hook 이벤트용 선택적 연결 도구입니다.
   어떤 hook도 자동 설치하지 않습니다. ChatGPT 웹 대화, 작업 내용, 내부 API를 읽지 않습니다.
   수동 상태는 실제 작업 성공을 증명하지 않습니다.

6. 남아 있는 범위
   - 현재 그림은 이전에 만든 공통·상호작용·전용 쓰다듬기 그림을 그대로 사용합니다.
   - 일부 보조 동작은 기존 프레임을 재사용합니다. 모든 동작에 새 전용 그림을 그린 것은 아닙니다.
   - 그림 비율/자연스러움과 실제 Windows 마우스·DPI·다중 모니터 사용감은 사용자가 확인합니다.
   - 공식 ChatGPT Pet 설치 및 16방향 시선은 이 독립형 프로그램에 포함하지 않습니다.
   - 서명되지 않은 개인 빌드입니다. 보안 프로그램 설정을 끄거나 보안 경고를 우회하도록 안내하지 않습니다.

원본과 수정 이력
   기준 소스와 이전 후보는 별도 원본 묶음으로 보존했습니다.
   동작 엔진 및 그림은 보존했고, 최신 불리언 설정 복구를 포함합니다.
   이번에는 일반 실행, 중복 실행 방지, 설정 폴더 분리, 화면 복귀 메뉴,
   Windows 빌드/휴대용 ZIP 생성, 배포 안내를 정리했습니다.
   assets 내부의 candidate/provenance 기록은 그림 승인 여부를 숨기지 않기 위해 유지했습니다.

7. 말풍선 시험본: 추론 강도
   - 말풍선의 설정 버튼을 누르면 모델 아래에서 추론 강도를 고를 수 있습니다.
   - 초기값은 '서버 기본값'입니다. 요청에 강도를 지정하지 않아 모델의 기본 동작을 사용합니다.
   - 직접 선택: none / minimal / low / medium / high / xhigh / max.
     모든 모델이 모든 단계를 지원하는 것은 아닙니다. 계정별 모델 목록에 지원 단계 정보가
     문서화되어 있지 않아, 직접 고른 단계의 허용 여부는 실제 요청에서 서버가 판단합니다.
   - 높은 단계는 응답 시간과 구독 사용량이 늘 수 있습니다. 별도 pro 모드를 켜는 설정이 아닙니다.
   - 다른 모델을 고르면 강도는 서버 기본값으로 돌아갑니다. 같은 모델의 목록 새로고침은 유지합니다.
   - 선택은 이 실행 중에만 유지됩니다. 앱을 다시 열면 서버 기본값입니다.
   - 지원하지 않는 단계가 거부되면 입력 문장을 보존합니다. 강도를 바꾸고 직접 다시 보내세요.
     자동 재전송, 자동 단계 변경, API 키 결제로의 전환은 없습니다.
   - 오프라인 시험은 UI와 요청 구성만 확인합니다. 실제 계정의 모델/강도 지원을 확인한 것은 아닙니다.
